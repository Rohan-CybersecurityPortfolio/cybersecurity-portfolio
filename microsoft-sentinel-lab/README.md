Microsoft Sentinel – SOC Investigation Lab
1. Project Overview

This project demonstrates practical Security Operations Centre (SOC) skills using simulated security event data and Microsoft Sentinel concepts.

The objective is to investigate suspicious authentication activity and identify potential security threats using Kusto Query Language (KQL).

2. Technologies
Microsoft Sentinel
Microsoft Azure
Kusto Query Language (KQL)
SIEM
Security Event Analysis
3. Investigation Scenario

A simulated organisation has experienced multiple failed login attempts.

As a SOC Analyst, my task is to:

Analyse authentication events.
Identify repeated failed login attempts.
Identify potentially suspicious IP addresses.
Investigate unusual authentication patterns.
Document findings and recommendations.
4. Detection Objectives
Detect repeated failed sign-in attempts.
Identify accounts experiencing suspicious activity.
Investigate potential password-guessing activity.
Recommend appropriate security controls.
